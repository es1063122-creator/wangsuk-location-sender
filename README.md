# 왕숙 현장 위치전송

남양주 왕숙 A-6BL 현장의 근로자 및 장비 위치를 현장 PC 서버로 전송하는 모바일 웹페이지입니다.

## 주요 기능

- 근로자 또는 장비 선택
- 장비 종류 선택
- 이름 또는 장비 호기 입력
- 휴대폰 GPS 위치 전송
- Firebase 미사용
- 단말별 최신 위치만 현장 PC에 저장

## 연결 구조

휴대폰 5G/LTE  
→ HTTPS 터널  
→ 현장 PC 로컬 서버  
→ Unity 실시간 위치 표시

## 개인정보 보호

실제 GPS 위치 데이터와 서버 저장파일은 이 저장소에 포함하지 않습니다.
